AI 助手 模型服务商 · 密钥 · 诊断解读 · 对话

服务商与密钥

启用关闭后 AI 对话与桌面助手均不可用
隐藏助手勾选后彻底隐藏右下角桌面助手（对话面板仍可打开）；取消勾选即恢复
记忆与经验默认关闭。启用后助手会记住你写的长期规矩，并从历史操作中学习失败模式以避免重复犯错；关闭时不再向模型注入任何记忆内容
「拉取模型列表」会调用服务商的 /models 接口获取在售模型；拉取失败时仍可用预置列表或自定义模型名。Key 经 DPAPI 加密存储，仅本机可解密。

能做什么

· 诊断报告 AI 解读：把脱敏诊断报告交给大模型，输出现状总结、问题定位与建议步骤
· 桌面助手：右下角 3D 桌宠——对话时思考 / 干活动画，长任务外圈进度环，写操作挂确认徽标（不用开抽屉直接批），出错红标一键跳到日志，检测完成开心撒花 / 皱眉点名缺什么，拖 .sql 文件到它身上直接生效，右键可归位 / 隐藏 / 立即检测
· 对话式能力：自然语言查询日志与环境状态，执行数据库备份、组件检测、前后端启停 / 重启、清理进程、加 Defender 白名单（共 11 个工具）
· 安全边界：所有写操作需你在对话或助手徽标上确认才会执行；Key 经 DPAPI 加密，不进日志、不进 AI 上下文

记忆与经验 让助手下次不再犯同样的错

记忆层当前未启用：以下内容可查看与编辑，但不会注入到模型对话中。请在「服务商与密钥」处开启「记忆与经验」。
我的记忆是你写给助手的规矩，它必须遵守；自动经验是系统从操作审计里统计出的失败模式，只是建议，你可以逐条否决。 优先级：你当场的明确要求 > 我的记忆 > 自动经验。
每行一条，支持 - 内容 | 标签 或 JSON 数组；重复内容自动更新而非新增
常记忆内容标签加入时间范围操作

自动经验 从操作记录统计，不是你在下的命令

类型结论成败置信度适用范围次数采用
置信度由这条经验自身的成败次数算出（同项目内统计）：高=多数时候成立、中=仅供参考、低不主动提示。 标「已失效」的项目/环境变了，该条不会注入——失效不删除，因为你需要知道它为什么不再被采纳。 自动经验是操作审计的统计视图，不单独存储；审计保留 30 天，过期的经验随之失效。

关于 EnvKit

EnvKit v__APP_VERSION__

统一开发环境助手 · Go + Node.js + MySQL 8 · 区块链溯源（FISCO-BCOS v2 / WeBASE）

作者 / 项目地址：https://github.com/hrui83771-gif

核心功能

  • 环境安装：Go / Node.js / MySQL 8 检测（版本 + 安装位置）、国内镜像下载（SHA256 校验 + 自动重试）、自动配置 GOPROXY 与 npm registry、演练安装、组件版本管理与一键升级
  • 程序配置：数据库连接检测、建库 + 建表一步到位、一键备份 / 还原（失败自动重试）、前端 npm install / 后端 go mod tidy、配置导入导出（支持脱敏分享）、环境诊断报告
  • 链端校验：FISCO-BCOS v2 / WeBASE-Front 连通检测、内嵌 SSH 终端、远程目录浏览、区块高度 / 交易总数 / 客户端版本读取、节点进程健康、宕机自动重启（一键检测 / 后台守护）+ 桌面通知
  • 程序启动：前后端一键启动（先后端、再前端）、访问地址自动解析、日志按来源分栏与 ANSI 清理、进程树管理（EnvKit 退出自动回收）、一键清理后台遗留进程
  • AI 助手：右下角桌面助手（任务进度环、写操作确认徽标、出错一键跳日志、拖入 SQL 直接生效、检测表情反馈）；自然语言问答与诊断报告解读，11 个工具覆盖状态 / 日志 / 诊断 / 数据库 / 检测 / 启停 / 白名单 / 清理，写操作一律先确认；兼容任意 OpenAI 协议模型，Key 经 DPAPI 加密
  • 安全与可靠：密码 DPAPI 加密存储、本机 API 令牌防 CSRF、单实例保护、配置原子写入 + 上一版备份、日志按日轮转与自动清理、panic 兜底与命令超时、杀软白名单一键排除 + 流氓软件深度清除
