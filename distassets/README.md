# EnvKit 使用说明（发给朋友请连这份文件一起发）

## 这是什么
一个 Windows 桌面工具：一键检测/安装 Go、Node.js、MySQL、JDK 17、Maven，配置并启动 Go + Vue 或 Spring Boot 项目（数据库建库、SQL 生效、前后端起停），内置 AI 助手与区块链链端（FISCO-BCOS / WeBASE）检测运维。

## 首次使用（3 件事）
1. **SmartScreen 蓝框拦截**：这是未签名 exe 的正常现象，点「更多信息 → 仍要运行」。
2. **装 MySQL 需要管理员**：右键 → 以管理员身份运行；只装 Go / Node.js / JDK / Maven 不需要。
3. **组件在线下载**：首次安装缺失组件需从 CDN 下载数百 MB（默认国内镜像）；如果 MySQL 下载慢，可去官网手动下载 zip，再在「环境安装」里选择本地文件。

## 配置
- 「程序配置」页填你的项目目录、数据库连接；右上角可导出/导入配置换机。
- 所有密码在本机用 Windows DPAPI 加密保存，换电脑后需重新填写。

## 数据库与数据浏览
- 「备份数据库」生成带 .sha256 校验和的备份，自动保留最近 10 份。
- 「生效 SQL」执行前会**自动备份**，高危语句（DROP/TRUNCATE 等）需二次确认。
- 数据浏览的「表数据」页，表有主键时可直接改单格，失焦自动保存；无主键表只读。
- 「SQL 查询」默认只读；写语句必须勾选「允许写操作」并二次确认。`DROP DATABASE` 只能走专用删库入口。
- 删除数据库需要二次确认并输入口令 `123456`，删除前自动 `mysqldump` 备份。该口令只用于防误触，不是安全边界。

## 手机访问（可选，默认关闭）
- 「程序配置 → 手机访问」打开后另开一个局域网端口（默认 18766），用手机扫二维码配对。
- 手机能看服务状态、点启停、和 AI 对话；还能看这台电脑的屏幕、读写剪贴板、开本机或链端终端。后三个各有开关，默认只有「看屏幕」是开的。
- 手机连不上，九成是 Windows 防火墙拦的：同一页点「检查防火墙」，需要时点「一键放行」（只放行手机端口，不放行控制台端口）。

## 遇到问题
- 「关于」页 → 一键诊断包：生成 zip（报告 + 脱敏配置 + 日志 + 审计），发给能帮你排查的人。
- 前端起不来、AI 报错等常见原因：看对应页面底部日志，杀软误拦时点「杀软白名单」。

## 卸载
运行包里的「卸载.bat」删除程序与快捷方式；组件目录（C:\EnvKit\tools）、MySQL 服务与环境变量不会被自动删除，说明里列了清理清单。
