# EnvKit · 统一开发环境助手

> 仓库地址：**https://github.com/hrui83771-gif/EnvKit**

面向 **Go + Node.js + MySQL 8** 一类项目的单文件、可视化、渐进式环境助手。
纯 Go 标准库实现（仅 SSH/WebSocket 两个轻量依赖），零运行时依赖，双击即跑；内置 Web 向导，浏览器自动打开。

## 界面
- **顶部全局状态条**：环境 / 数据库 / 依赖 / 服务 四个状态点，点击直达对应路由；非管理员时显示「以管理员身份重启」（UAC 提权重启）。
- **右侧状态感知边栏**：四个路由（环境安装 / 程序配置 / 链端校验 / 程序启动）；底部「运行状态」卡显示前端、后端、WeBASE-Front 是否可达、访问地址（可点「打开」）与「停止全部」；侧栏底部「关于 / 免责声明」。
- 每个路由底部有**独立实时日志**（按 scope + 来源分流）；**「程序启动」页把前端、后端日志拆成两个面板**，互不干扰。
- 日志会**自动清理 ANSI 转义码**、按回车重绘丢弃半行、折叠相邻重复行，不再出现乱码。
- 每个日志面板默认可折叠，带 复制 / 下载 / 浅色 / 自动滚动 / 清空 工具条。
- **自动保存**：配置改动 800ms 防抖自动写盘；**前置校验**置灰缺前置条件的按钮；**运行互斥**（HTTP 409）；**二次确认**保护破坏性操作。

## 四个路由

### 1. 环境安装（检测 → 配置 → 安装 → 完成）
- **检测**：报告每个组件的「版本 + 安装位置」，已装的标「已安装」并跳过。
- **配置**：安装目录、各组件下载源（默认国内镜像）、MySQL 参数、下载代理、语言代理。
- **安装**：官方绿色 zip 自解压、写用户级 PATH、初始化 MySQL 并设密码；
  完成后自动设置 `GOPROXY`（goproxy.cn）与 `npm registry`（腾讯云镜像）。
- **下载可靠性**：失败自动重试（共 3 次）；组件可配 `sha256` 字段做完整性校验，不符即删重下。
- 失败有明确提示（404 / 网络不可达 / 缺 VC++ / 权限不足）并给出处理建议。

### 2. 程序配置
集中配置「前端目录 / 后端目录 / MySQL 连接 / 数据库名 / SQL 文件」，持久化到 `config.json`。
- **配置导入 / 导出**：一键导出 `envkit-config.json`（可选**脱敏**：去除所有密码），换机迁移或分发模板；
  导入时空密码字段自动保留本机已有密码。
- **数据库连接检测**、**建库 + 建表一步到位**、**前端 npm install**、**后端 go mod tidy**（走 GOPROXY）。

### 3. 链端校验（FISCO-BCOS v2 / WeBASE-Front）
- **SSH**：连接测试、远程执行命令、**内嵌 Web 终端**（xterm.js + WebSocket 桥接 SSH PTY，页面内直接操作远程 shell，支持窗口自适应与缩放同步）、外部真实 ssh 窗口兜底。
- **远程目录浏览**：链端 / WeBASE 目录旁「选择」经 SSH 浏览目标 Linux 目录点选。
- **启动脚本默认值**：链端 `bash start_all.sh`、WeBASE `bash start.sh`；经 SSH 以**登录 shell + setsid** 执行（加载 JAVA_HOME 且脱离会话不被杀）。
- **智能检测**：
  - 区分「公网不可达但节点存活（仅本地绑定）」与「节点真挂了」，不再误报；
  - 统计远程 `fisco-bcos` **节点进程存活数**，任一节点挂了都能看见（不只 node0）；
  - WeBASE-Front REST 读取**区块高度 / 交易数量 / 客户端版本**。
- **宕机自动重启**（可选开关 `chain_autorecover`）：一键检测发现节点/WeBASE 宕机自动拉起并复检；**自动恢复可视化**（累计次数 + 最近时间）。
- **轮询就绪**：启动后每 2s 轮询端口/REST，就绪即提前返回，超时早报（不再死等 30s）。

### 4. 程序启动
- 前端 `npm run serve|dev`、后端 `go build ./...` + `go run main.go`，后台运行可停止。
- **地址自动解析**为可点「打开」按钮；**停止杀整棵进程树**。
- **进程守护（Job Object）**：所有子进程绑定到 Windows Job，EnvKit 无论以何种方式退出（关窗口 / 被杀 / 崩溃），子进程树都会被系统自动回收，不留孤儿占端口。
- **cgo 自动回退**：无 gcc 时自动 `CGO_ENABLED=0`。
- **端口占用一键诊断**：解析 netstat 找出占用进程名与 PID，可选一键结束（带二次确认与自身保护）；启动脚本支持自定义并记住历史。
- **网页端「退出程序」**：可选只退出助手（服务继续在后台运行，Windows 上通过复制 Job 句柄保活）或连带停止启动的服务。

## AI 运维助手（小画师）
右下角桌面助手 + 对话面板，兼容任意 OpenAI 协议模型（baseURL / 模型 / Key 可配，Key 经 DPAPI 加密存储）。
- **11 个工具**覆盖系统状态、日志检索、数据库检查、环境检测、服务启停 / 重启、备份、Defender 白名单、进程清理等；写操作一律先弹确认卡，高危操作红框警示，服务端强制二次确认（428）。
- **感知快照**：每回合自动注入环境状态与最近错误摘要，AI 第一轮就带着现状作答。
- **滚动摘要**：长对话自动把较早内容压缩成要点备忘，最近消息原样保留，不再"越聊越忘"。
- **防提示注入**：日志等外部内容以不可信定界符包裹，系统提示词声明处理规则。
- **透明可控**：AI 的每次写操作都计入审计（actor=ai），用量与余额可见，停止生成随时中断；对话历史本地持久化，出错一键跳日志或让 AI 分析。
- **无 Key 也能聊**：AI 未配置时功能完整降级，助手表情会随检测 / 出错 / 启停联动（连点还有彩蛋）。

## 使用方法
1. 把 `EnvKit.exe`（连同可选 `config.json`）发给目标机。
2. 双击运行，浏览器自动打开向导（`http://127.0.0.1:18765`，端口自动避让）。
3. 按「环境安装 → 程序配置 → 链端校验 → 程序启动」四步推进。

## 前提
- **MySQL 绿色版需要 VC++ 2019 Redistributable (x64)**：
  https://learn.microsoft.com/zh-CN/cpp/windows/latest-supported-vc-redist
- 首次运行需联网（下载约 180MB 组件压缩包；可填下载代理加速）。
- 注册/启动 MySQL 服务需要**管理员权限**。

## 自定义（不改代码）
在 `EnvKit.exe` 同目录放一份 `config.json` 即可覆盖内置默认：
组件版本 / 下载 URL / `sha256` 校验、`goproxy`、`npm_registry`、下载代理、`mysql`、`projects`、`chain`（SSH 与链端配置）。

## 重新编译
```
build.bat
```
图标与文件属性（版本信息）已通过 `resource.syso` 编入 exe，无需安装任何工具即可直接 `go build`；
升级版本号时同步修改 `versioninfo.json` 并重新生成资源（命令见 build.bat 内说明）。
版本号 / 构建日期经 `-ldflags -X main.appVersion / main.buildDate` 注入，显示在「关于」弹窗与 exe 属性面板。
可选压缩：`upx --best --lzma EnvKit.exe`（约 7MB → ~2.5MB）。

## 测试
```
go test ./...
```
前端回归使用 CDP 驱动真实 Chromium（`tools/cdp_*.js`，Node 22 原生 WebSocket），
HTTP 链路回归见 `tools/test_*.py`；`tools/dist_check.py` 在出分发包前做泄漏扫描。

## 架构
- `main.go`：Web 服务 + SSE 实时日志 + 路由注册 + 配置导入导出。
- `detect/install.go`：环境检测与安装（下载重试 / SHA256 校验）。
- `program.go / exec.go / portscan.go`：项目配置、前后端启停、进程树、端口诊断。
- `dbops.go`：建库建表、备份 / 还原 / 演练。
- `chain.go`：链端校验（SSH / 端口 / REST / 远程启动 / 自动恢复）；`webterm.go`：WebSocket → SSH PTY 桥接（内嵌终端）。
- `ai*.go`：AI 助手（工具注册表、意图回溯、滚动摘要、感知快照、确认闸门）。
- `winjob_windows.go / console_windows.go`：Windows Job Object 进程守护与控制台生命周期。
- `audit.go / securityMW / persist`：审计、API 令牌防 CSRF、配置持久化。
- `web/index.html`：向导前端（内嵌编译进 exe）；`web/xterm/`：终端静态资源。
- `config.dist.json`：内置默认配置模板；`config.json` 可外部覆盖（不入库）。
