   `handleAIChat` 原来是「先 `aiChatReady(w)` 刷 SSE 响应头 → 再读 `r.Body`」。

### 这一轮定下的不变量（改之前先看）

- **`aiMd()` 的输出必须先过 `aiSanitizeHtml()`**：模型输出是不可信输入（日志、网页、文件都可能进上下文）。净化只放行白名单标签，`script/iframe/svg` 整个丢弃，`on*` 全删，`javascript:` 链接拆掉，外链图片不加载。
- **复制仍取 `dataset.raw`（原文）**，不要改成 `innerText`：渲染后的文本带表格/代码块结构，复制出来是坏的。
- **vendor 的两个库走 exe 内嵌**，不要改回 CDN 链接——本工具常在无外网的客户现场跑。
- **流式期间不高亮**（每帧 innerHTML 重建会让高亮元素作废，等于每帧重跑 hljs）；收尾 `streamDone=true` 后统一高亮一次，别在 `flushRender` 里加高亮。
- **日志折叠按钮的文案必须由 `collapsed` 状态推导**（`ekSyncLogToggle`，初始化与切语言时都会跑）。标记层只写初始态；按钮写死「折叠」会造成"日志已收起、按钮却写着折叠"，第一次点击反而展开——实测被当成 bug 报上来过。
- **CDP 脚本先杀残留实例**：EnvKit 有单实例保护，上一轮没退干净时新 exe 会立刻自行退出，浏览器连到旧页面后能跑出"全绿"的假结果（`_cdp_*.py` 里的 `ensure_no_stale_instance` 就是为此加的）。
- `go.mod` 现在是 `go 1.26.0` + `golang.org/x/sync v0.20.0`；本机 go 1.25 由 `GOTOOLCHAIN=auto` 切换（x/sys 早已要求 1.26）。

### 托盘/记忆层的坑

- **托盘 RunTray 必须在主 goroutine 调用**：systray 在包 init 里 `LockOSThread`，换 goroutine 会出现"图标在、点了没反应"。HTTP 服务已改成后台 goroutine。
- 托盘菜单动作全部走回调注入（platform 是叶子包），**不要在 platform 里 import 业务代码**。
- 「退出」必须自己 `shutdownChildren()`：托盘没有 Ctrl+C，少了这步会留一堆前端/后端孤儿进程。
- `memoriesView` 是界面与注入的**唯一口径**：以后加"最近使用 / 命中次数"也放这里，别在 API 里另算一套。
