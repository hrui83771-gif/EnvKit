## 零、与 v3.0 稿的关系：继承 / 舍弃 / 新增

v3.0 稿的方向（状态中心、唯一数据源、验证纪律）全部继承；它的"5 个工作区"是本稿要减掉的部分。
先划清界限，避免下一个人照着旧稿做决策。

| | 内容 | 处置 |
|---|---|---|
| **继承** | 状态唯一来源（rtStore）、绿=已复验（§4.2 灯语义）、桌宠零删减、AI 交互零删减、i18n 全走 `t()`、收起≠删减、能力可达性对照表 | 一条不改，本文引用不重写 |
| **舍弃** | 六面板平铺（install/config/chain/start/ai/audit）、5 工作区导航（运行/诊断/数据/助手/设置）、"首页只读不做操作台" | 首页就是操作台（服务行的复验/重启原位保留）；工作区收缩为配置页的分组 |
| **新增** | iOS 设计语言（大标题/分段控制/inset 分组/毛玻璃/弹簧曲线）、翻转面板（主进程↔AI）、配置页搜索、守护与晋升区块 | 本文主体 |

**净变化**：导航 6 → **2**（状态 / 配置）。能力一个不减，全部搬进这两页——
减的是入口数量与视觉噪音，不是功能。

## 一、信息架构

```
EnvKit（单窗，无侧栏，无多页签）
├─ 分段控制：［状态］［配置］                    ← iOS segmented control
│
├─ 状态页 —— 只回答"现在怎样、我要干什么"
│   ├─ 大标题"状态" + 数据时间 + 主题钮
│   ├─ 翻转主卡（本稿核心，见 §二）
│   │    正面：主进程（服务键驱动 + 守护条 + 当前活动）
│   │    背面：AI 助手（同一 #ai-msgs，零删减搬迁）
│   ├─ 基础设施：数据库 / 链端 / 依赖
│   ├─ 需要处理：issues 逐条 + action 出路
│   └─ 最近：audit 尾部
│
└─ 配置页 —— 所有配置与统计的唯一收纳处
    ├─ 搜索框（实时过滤分组行）
    ├─ 组（inset 分组列表，默认全折叠）：
    │    组件 / 项目 / 链端 / 守护与晋升 / AI / 统计与审计
    │    └─ 每组带日志抽屉（原四路由 SSE 日志收纳于此）
    └─ 底栏：保存（带脏状态圆点）
```

### 1.1 现有 6 个面板的归属

| 现有面板 | 源码锚点 | 去向 | 理由 |
|---|---|---|---|
| `install`（环境安装） | `index.html:467` | 配置 › 组件 | 安装是配置行为；压成设置区一个折叠组，含镜像加速/SHA256/演练 |
| `config`（程序配置） | `index.html:546` | 配置 › 项目 + 链端 | 本来就是配置形态，按对象拆成两组 |
| `chain`（链端运维） | `index.html:683` | 状态页基础设施行 + 配置 › 链端 + `⋯` 菜单 | 查状态进状态页；SSH/端口等低频操作收进行的 `⋯`；重启链端等破坏性操作收 `⋯` 且警示色 |
| `start`（程序启动） | `index.html:776` | 状态页服务行 | 启停/复验是主功能，永远可见；进程树/端口诊断/白名单收 `⋯` 或组内日志抽屉 |
| `ai`（AI 助手） | `index.html:846` | **翻转主卡背面** | 用户点名"一面主进程一面 ai"；与桌宠抽屉并存的第三个停靠点 |
| `audit`（操作审计） | `index.html:941` | 配置 › 统计与审计 | 审计是"回看"，不是日常；7 天试运行期间它是首页"最近"区的数据源 |

**四路由的独立日志**（环境/配置/链端/启动，SSE `{scope,line}`）不丢：
收纳为配置页对应分组内的**日志抽屉**，每组一个，默认折叠。

## 二、翻转主卡规格（本稿核心）

### 2.1 正面：主进程

| 元素 | 内容 | 数据 |
|---|---|---|
| 卡头 | "主进程" + ↻ 翻转钮 + 相对时间（"3 秒前"） | rtStore 拉取时间 |
| 服务行 × N | 状态灯 + 名称 + 端口/运行时长/连续失败 + **最多 1 个主动作**（复验/重启） | `services.*`（键驱动，见 §五） |
| 守护条 | 链端守护开关态 + 最近自动恢复 + 影子晋升进度（n/20） | `/api/guard/status` |
| 当前活动 | 任务执行中的进度（启停/备份进行时） | `/api/program/state` |

**服务行必须键驱动**：后端给几个服务就渲染几行，前端不得枚举服务名。
这是后端 T2.1–T2.9"拓扑无关化"在 UI 层的镜像——前端写死 `web`/`backend` 两行，
就是把后端刚消灭的"为每种环境复制一套"在 UI 层复辟。

### 2.2 背面：AI 助手

**不是新聊天框，是现有 `#ai-msgs` 的第三个停靠点。** 沿用 v3.0 稿 §D.4 纪律：

- 消息渲染、token 行、计划展示、确认卡、思考折叠、停止生成、时间戳——一处不改；
- 与桌宠抽屉（`#ai-drawer`，`index.html:1253`）、原助手页**共用同一份 `aiHist`**；
- 翻面不重置滚动、不中断 SSE 流（用户翻到背面问一句，翻回正面，流继续渲染到背面）。

### 2.3 翻转交互

| 项 | 规格 |
|---|---|
| 触发 | 卡角 ↻ 圆形按钮（主触发）+ 双击卡面 + 键盘（卡聚焦时 Enter 翻转、Esc 翻回正面） |
| 动效 | `perspective:1200px` + `rotateY(180deg)`，0.55s，Apple 弹簧曲线 `cubic-bezier(0.32,0.72,0,1)` |
| 降级 | `prefers-reduced-motion: reduce` → 交叉淡入，**功能不减**（不是"不翻转就不能用"） |
| 焦点管理 | 翻到背面聚焦输入框；翻回正面焦点还给 ↻ 钮 |
| 状态保持 | 翻面/切页/折叠都不重置对话态、滚动位、流式缓冲区 |

### 2.4 桌宠：弃用（2026-10-19 用户决策，见 §十一）

> **决策记录**：用户 2026-10-19 原话「你可以抛弃我原有的桌宠设计，转为更简约的形象，
> 我需要更有科技感更有灵性的网页」。**本条推翻两处 prior 决策**：
> v3.0 稿 §D「桌宠零删减」（用户当时明确要求保留）与本稿初版 §2.4「原样保留」。
>
> 桌宠 SVG 系统（表情/发型/彩蛋/右键菜单）整体弃用；其**功能**（快速召唤 AI、
> 状态提示、用量与余额、拖拽停靠）由新形象「核」继承，处置对照表见 §十一.4。
> `#ai-drawer` 抽屉本体保留——它是 AI 的第二停靠点，与桌宠形象是两回事。
>
> **2026-10-19 再次确认**：用户原话「我推荐暂时放弃桌宠在这一版中」——与上一条决策
> 同向，本版 UI 中桌宠不出现（连占位都不渲染）；SVG 资产保留在仓库但不挂载，
> P2 批次删除，commit message 引用本条决策。

## 三、视觉规范（iOS 设计语言落地）

### 3.1 色彩（复用现有 `[data-theme]` 变量体系，不新造）

| 角色 | 亮色（纸面） | 暗色（夜色水彩） | 用途 |
|---|---|---|---|
| 页面底 | `#faf8f5` | `#1c2333` | 暖纸底；暗色**不是纯黑**（禁止项） |
| 卡片/组 | `#faf8f5` 92% 不叠底 | `#232c40` | inset 分组、翻转卡（纸下透出晕染） |
| 主文字 | `#3a3a3a` | `#e9e5dc` | 大标题、行名 |
| 次文字 | `#4a6fa5` | `#9db8dc` | 指标、组标题 |
| 弱化文字 | `#6b6b66` | `#98a0b3` | 脚注（原 `#8a8a8a` 在纸底不达 AA，加深，见 §12.4.1） |
| 强调/按钮 | `#4a6fa5` 85% | `#9db8dc` | 保存、分段控制选中、链接 |
| 发丝线 | `rgba(74,111,165,.20)` | `rgba(157,184,220,.22)` | 行分隔（inset 对齐名称列） |
| 成功 | `#78a082` | `#8fbf9a` | **仅已验证的成功** |
| 警告 | `#c9a84c` | `#d8bc6a` | 降级/未复验/待办 |
| 失败 | `#b4788c` | `#c98a9b` | 失败/不可恢复 |
| 水彩颜料（半透明使用） | 蜜桃 `#e8a87c` / 青绿 `#85cdca` / 玫瑰 `#c38d94` / 沙 `#d4a373` | 同色降饱和 | 背景晕染块、核的三色内核 |

硬要求（继承 v3.0 稿 §B）：所有颜色走 `var(--*)`，主题块之外零硬编码；
亮暗同名同义；切主题只改 `<html data-theme>`，DOM 不重建。

**状态灯四色语义照搬 v3.0 稿 §4.2，一条不松**：
绿 = `running && verified`；黄 = `degraded`/在跑未复验/有待办；
红 = `failed`；灰 = `stopped`。"执行不等于成功"必须看得见。

### 3.2 字体与层级

| 层级 | 字号/字重 | 用在哪 |
|---|---|---|
| 大标题 | 28px / 600（滚动后收缩为 17px 内联标题） | 状态 / 配置 |
| 组标题 | 13px / 400，次文字色，全大写感（iOS footnote 风格） | 基础设施 / 需要处理 / 各配置组 |
| 行名 | 15px / 400 | 服务行、配置行 |
| 行指标 | 13px / 400，次文字色 | 端口、时长、版本 |
| 主数值 | 22px / 600 | 影子晋升 n/20、块高等关键数 |

字体栈：`-apple-system, "SF Pro Text", "PingFang SC", "Microsoft YaHei", sans-serif`
（Windows 上自然回退到雅黑，不引 Web 字体——单 exe 分发零外部依赖）。

### 3.3 形状与材质

- 圆角：配置组/翻转卡 `rounded-3xl`（24px）、按钮/输入 `rounded-2xl`（16px）、
  pill/分段/进度条全圆角、↻ 钮正圆——**禁直角**（风格库禁止项）；
- 分隔线：1px 发丝线 `rgba(74,111,165,.20)`，**左缩进对齐名称列之后**（inset separator），不是通长；
- 材质：**纸面，不是玻璃**——顶栏/底栏用 92% 不透明纸底 + 柔影；`backdrop-filter`
  毛玻璃退场（风格库明令"不得把玻璃态当默认风格"）；页面底层可放 2–3 枚
  `blur(60px)` 水彩晕染色块（蜜桃/青绿/玫瑰，透明度 ≤.35）作氛围；
- 间距：8pt 栅格；组与组 18px，组内行 12px，行内元素 8px；
- 投影：三档柔影（见 §12.2），全部低透明度蓝灰——**层次来自留白、发丝线与
  一层柔影，不来自阴影堆叠，更不来自硬边框**。

| 场景 | 曲线 | 时长 |
|---|---|---|

| 翻转卡 | 同上 | 0.55s |

## 四、交互细节

1. **行规范**（继承 v3.0 稿 §3.4.1）：名称列固定 96px 等宽 → 所有行名称竖向对齐；
   指标列自适应；操作列贴右，**每行最多 1 个实心按钮**，其余进 `⋯`。
2. **`⋯` 菜单**：低频与破坏性操作（重启链端、端口扫描、结束进程、还原业务库）。
   菜单内按钮仍在 DOM、仍走确认流程——**收起 ≠ 删减**。
3. **配置页搜索**：输入即过滤（匹配行名与组名，命中组自动展开）；
   空结果显示"没有匹配的设置" + 清除按钮。搜索是"极简"的兜底：
   折叠掉的东西必须能被一句话找到。
4. **保存模型**（待拍板，见 §十）：iOS 式即存（开关/选择变更立即落库，行内显示
   "已保存"脚注 2 秒）或底部统一保存 + 脏状态圆点。二选一，不混用。
5. **脏状态**：未保存的组标题右侧显示橙点；离开配置页时若有未保存项，
   底部弹出 iOS 风格行动列表（保存/放弃/取消）。
6. **空状态与失败态**：无服务时显示"尚未配置任何服务" + 去配置入口；
   拉取失败显示"状态获取失败"横幅 + 重试——**绝不渲染成"一切正常"**
   （与 rtStore 的 `ok` 标志分离设计同源，v3.0 稿 §5.2）。
7. **日志抽屉**：每组行尾"日志"入口，展开为该路由 SSE 流的滚动区，
   带暂停/继续与清空；执行任务时对应组的抽屉自动展开一次。
8. **键盘可达性**：全功能可 Tab 到达；翻转卡、`⋯` 菜单、分段控制均有焦点样式；
   Esc 关闭菜单/抽屉/翻回正面。

## 五、数据契约（诚实清单：已接什么、缺什么）

| 数据 | 来源 | 前端现状（源码锚点） | 新设计用途 |
|---|---|---|---|
| services 键清单 + phase/verified | `/api/runtime/state` | **零直接接入**（全文 0 处引用） | 状态页服务行唯一渲染源，键驱动 |
| issues（含 action） | `/api/health`（runtime 派生） | 已接入：`renderIssues`（`index.html:3493`，调用点 3394） | "需要处理"区 |
| 守护运行态 + 最近动作 | `/api/guard/status` | 已接入：`loadGuardStatus`（`index.html:2634-2675`） | 守护条 |
| **守护晋升就绪度**（route/passes/need/blockers） | 同上，`shadowStatusForAPI`（`shadow.go:434`） | **零消费**（loadGuardStatus 只读 `status`/`recent`） | 守护条进度 + 配置 › 守护与晋升 |
| 操作审计 | audit API | audit 面板自用 | 状态页"最近" + 配置 › 统计与审计 |
| AI 对话 | SSE + `#ai-msgs` | 桌宠 + 助手页两处停靠 | 翻转卡背面（第三处，同 DOM） |
| 启停进度 | `/api/program/state` | `pollProg` | 服务行"当前活动" |

**两处对 v3.0 稿的修正**（稿成于 v2.7 之前，结论已过期）：
①"issues 前端 0 引用"——v2.7 已落地 `renderIssues`，经 `/api/health` 兼容层；
②"`/api/guard/status` 前端零接入"——已接入，但只消费运行态，**晋升就绪度没接**。
P1 的真正的活儿因此变小：不需要新建兼容层，把 `pollHealth` 改成读 rtStore 即可。

**实现必读的坑**（v3.0 稿 §4.3 复述，仍有效）：`RuntimeState` 命名风格不统一——
`services`/`db` 是 snake_case，嵌进来的 `ChainInfo` 是 camelCase（`blockNumber`/`port20200`）。
取值照抄 JSON tag；若认定是设计失误，在 Runtime 层统一，**不在前端做兼容映射**。

## 六、配置页分组与能力可达性

| 组 | 收纳 | 默认态 |
|---|---|---|
| 组件 | 环境检测、组件安装/版本/缺失、镜像加速、SHA256、演练安装 | 折叠 |

| AI | 服务商、密钥、模型、记忆开关 | 折叠 |
| 统计与审计 | 今日 token/对话/命中率、审计列表（30 天）、诊断包导出 | 折叠 |

**能力可达性清单直接复用 v3.0 稿 §5.3 的 22 行对照表**，把"新入口"列按上表改写，
P3 逐条核对——"重组不删能力"没有对照表就只是一句口号。

**密度判据的重新锚定**：`tools/density.js` 现断言 `.c 卡片 = 0`、实心 < 10、
默认可见 ≤ 40。新设计的容器从 `.c` 变成 iOS inset 组，**选择器要跟着改，意图不变**：

### 12.3 「科技感 × 水彩」的裁定（用户此前要"科技感+灵性"）

两者不冲突，分工明确：**科技感来自"每个像素都有真实事件背书"**——核的呼吸跟着
轮询走、涟漪跟着 token 走、闪绿只由复验通过触发；等宽字体承载版本/时间/计数。
**水彩负责柔**——纸底、晕染、慢动效。一个管行为，一个管材质。
若哪天为了"好看"加了无事件驱动的装饰动画，那是漂移，验收第 8 条会抓到。

### 12.4 与既有纪律的冲突裁定（按优先级）

1. **对比度优先于色板**：风格库弱化色 `#8a8a8a` 在 `#faf8f5` 上约 3.4:1，
   不达 WCAG AA；正文弱化改用 `#6b6b66`（约 5:1）。色板让位于可读性——
   这正是风格库无障碍条目自己要求的。
2. **彩色背景上不放灰字**：状态 pill 一律"色底 15% + 深墨字"。
3. **禁嵌套卡片**：配置页分组 = 一张卡内多行 + 发丝分隔；行内不再套卡
   （策略表行、审计行、确认卡同理——确认卡用色底+发丝边表达，不做"卡中卡"）。
4. **禁渐变文字**：标题纯色衬线，不用 `background-clip:text`。
5. **动效只走 transform/opacity + 颜色**（§八.11 性能预算）；模糊只允许出现在
   背景装饰晕染块上，不动本身属性。
6. **reduced-motion**：翻面降级淡入、呼吸与涟漪停止、hover 晕开消失——
   **功能一项不减**（§八.5/10 照验）。

### 12.5 「核」的水彩化身

视觉 = **一滴落在湿纸上的颜料**：外环蓝灰细线 + 内核三色 radial 轻染
（蜜桃→青绿→玫瑰，低透明）+ 一枚跟随指针的高光。六态状态机与驱动源
**一字不改**（§11.3），只是材质换成水彩：呼吸 4.5s（更慢，配合液态缓动）、
涟漪 1.8s 扩散、闪绿用 `--ok`。反面纪律不变：idle 态禁止 ripple 类名。

## 十一、形象系统：桌宠 → 「核」（2026-10-19 决策）

> 触发反馈：用户认为上版原型"交互感不强"，要"更有科技感更有灵性"。
> 本章是响应：**页面的灵性不靠装饰，靠一个对真实事件敏感的形象 + 一组零视觉常驻成本的交互入口。**

### 11.1 概念

「核」（Core）= **一个圆**：外环 + 核心 + 一枚跟随指针的高光。没有五官、没有肢体、
没有表情包。它的"灵性"来自一条硬规则：**每一个视觉变化都必须由真实事件驱动**——
SSE 的一个 token、守护的一次自动恢复、探针的一轮心跳。没有事件时它就在呼吸，
而呼吸的节拍就是轮询的节拍——"这个页面是活的，而且在真的看"。

### 11.2 构成与尺寸

| 元素 | 规格 |
|---|---|
| 外环 | 1.5px，状态色 40% 不透明度；活动态升至 100% |
| 核心 | 10px 圆点，状态色实心 |
| 高光 | 3px 白点，跟随指针（可关） |
| 尺寸 | 静息 36px / 悬停 40px / 活动态 44px；**点击热区 ≥ 44px**（小于 44px 是在罚用户的手指） |
| 位置 | 全局右下，可拖拽，边缘吸附左右；位置记忆 `localStorage` |
| 挂点 | 两个：全局悬浮 + 翻转主卡卡头（同一组件，翻面时卡头那枚与全局那枚状态同步） |

### 11.3 状态机（六态，全部事件驱动）

| 态 | 驱动源（真实事件） | 视觉 | 动效 |
|---|---|---|---|
| idle 静息 | 无进行中的事；探针轮询 heartbeat | 环 40% / 核心状态色 | 呼吸 scale 1→1.05，4s，**节拍=轮询周期** |
| listening 聆听 | 用户聚焦 AI 输入框 | 环 100% | 环慢转 6s/圈 |
| thinking 思考 | SSE `reasoning` 事件 | 核心亮 20% | 双弧绕核旋转 1s |
| streaming 输出 | SSE `delta` 事件 | 涟漪源 | 每 token/200ms 一圈 ripple 从核扩散（scale 1→2.2 淡出） |
| ok 达成 | 复验通过 / 任务成功 / 恢复成功 | 绿 | 400ms 闪 + 环补完一圈 |
| warn 异常 | SSE `error` / 守护不可达 / 复验失败 | 琥珀或红 | 环抖动一次（±1px，150ms） |

**反面断言**（写进测试）：idle 态不得出现 ripple/通知类名。宁可"什么都不发生"，
不要"看起来发生了什么"——这和守护判据的纪律同源。

### 11.4 桌宠资产处置（继承 / 变形 / 弃用）

| 桌宠资产（v3.0 稿 §D.1-D.3） | 处置 |
|---|---|
| 4 种眼状态 / 8 面部特征 / 3 发型 | **弃用**（形象整体放弃） |
| 点击反馈 bubble/badge | 变形为环境提示气泡（11.6） |
| 任务提示浮层（tip/task/name/elapsed/last/usage） | 变形：进行中事件进"当前活动"行 + 核气泡 |
| 今日统计 / 缓存命中率 / 余额四态 | **保留**为核悬停卡（计费四态 idle/ok/no/err 不变，v3.0 稿 §D.3） |
| 右键菜单 4 项 | 精简为 3 项：召唤 AI / 停靠左·右 / 高光跟随开关 |
| 眼睛跟随开关 | 变形为高光跟随 |
| 拖动 / 贴边（petShift） | **保留** |
| 彩蛋对话 pet-mc | **弃用**；仅保留一个：连点 5 次核旋转一周（一行 CSS 的成本） |

### 11.5 交互升级包（回答"交互感不强"）

七项，全部零新增能力、只增入口与反馈——"收起 ≠ 删减"的终极形态是**不存在时才出现**：

| # | 交互 | 说明 |
|---|---|---|
| 1 | **⌘K 命令面板** | 模糊搜索全部动作（启停/复验/备份/问 AI/跳配置组/导出诊断包）；↑↓ 选择、Enter 执行、Esc 关闭。破坏性操作在面板里同样走 needConfirm——**不因入口不同而放水** |
| 2 | 键盘直达 | ⌘1/⌘2 切页；Esc 层级关闭（菜单→气泡→翻面） |
| 3 | 翻转卡指针视差 | ±4° tilt + 核高光同源跟随；reduced-motion 下关闭 |
| 4 | 数字滚动 | 12/20、块高、token 变化时 400ms rollup |
| 5 | 灯脉冲 | 状态灯数据变化时脉冲一次；**颜色先出、动画后到**——变化本身永远第一 |
| 6 | 行进披露 | 行悬停/聚焦才显示次级动作（⋯），默认视野只有主动 |
| 7 | 流式涟漪 | 翻面背面随 token 节奏从输入框边缘泛起微漪（transform/opacity，无 canvas） |

### 11.6 环境提示（核的"嘴"）

守护动作或问题出现时，核旁 6 秒气泡：「链端已自动恢复 · 查看」/「后端未复验 · 去复验」。
点击气泡跳转到对应区域（审计/守护条/服务行）。**它替代桌宠 tip 浮层，但只报真实事件**——
是否默认全开待拍板（§十.5）。

### 11.7 工程红线

- 核 = **一个 DOM 节点 + CSS 动画**，不引库、不上 canvas；长跑性能预算是硬验收（§八.11）；
- 全部状态类名由事件切换，**禁止定时器伪造状态**；
- 桌宠 SVG 代码删除放在 P2 批次，commit message 必须引用本条决策（用户原话+日期），
  让"删掉两千行既有资产"在历史里可追溯；
- 悬停卡的计费四态是 v2.0 定下的纪律（"查不到"不能显示成"有余额"），随搬迁不合并。
- 核的水彩材质（三色 radial 内核、慢呼吸、涟漪时长）见 §12.5；状态类名与
  事件驱动规则不变——**换材质不换状态机**。
