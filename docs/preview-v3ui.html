从"一功能一卡"回到"有层级的轻"

上一版 33 张卡 / 75 个按钮 —— 那是后台管理面板的量级。 这一版不靠压缩间距，只改信息层级。

1 · 只有一种容器：区块 + 状态行

不再有"卡片"。一个区块 = 标题 + 若干状态行 + 可选底部动作条。 一行 = 名称 + 状态 + 关键指标 + 最多两个操作。

效果：33 张卡 → 10 个区块；同一屏能看完的事，不需要滚动。

2 · 相关功能合并

  • 运行页：前端 / 后端 / 整套启停 → 一个「服务」区块，三行
  • 运行页：进程 / 端口 / 白名单 → 折叠区「进程与端口」
  • 诊断页：9 张卡 → 环境与服务 / 链端 / 日志与报告 三个区块
  • 助手页侧栏：4 张卡 → 3 个小区块（今日 / 最近任务 / 经验）

3 · 按钮分两级

核心操作是实心按钮（复验、重启、备份、全部启动）， 次要操作是文字按钮（停止、详情、修改、重查）—— 视觉重量接近文字，扫视时不抢眼。

破坏性操作（还原、重启链端）用文字按钮 + 警示色， 不占视觉主位，但点击仍需确认。

4 · 低频收进折叠

进程、端口、白名单、组件安装、SSH 主机 —— 这些是"偶尔才用"的事， 收进 <details>，标题写清"偶尔才用"。 高频的（服务启停、复验）永远直接可见。

5 · 首页只回答两个问题

现在什么状态（服务 + 基础设施两个区块）、 哪里需要处理（唯一强调的区块）。最近动作退化成一行文字。

"需要处理"是页面上唯一需要视觉强调的地方—— 因为它是唯一要你动手的东西。其余都安静。

6 · AI 交互一处未删

系统消息 · 时间戳 · 思考折叠 · 执行计划（含提额行） · 工具结果折叠 · 单次 token 行 · 写操作确认卡 · 停止生成 · 清空 · 桌宠悬停卡 （任务 / 上次 / 今日统计 / 缓存命中率 / 余额 + 刷新）。

助手页方形与右下角抽屉是同一套对话（同渲染、同历史、同状态）， 只换挂载点——不会割裂。

7 · 亮暗色、中英文仍完整

沿用现有 [data-theme="dark"] 的 21 个变量，主题块外零硬编码颜色。 右上角 ◐ 切换。英文走原有 t()。

8 · 状态灯规则仍可对照

勾上「按旧规则上色」，后端立刻变绿——但它 phase=degraded。 这条不能因为变简洁就丢掉。
