## 一、日志：有标签的行只信标签

界面「这行标不标红」和「这行要不要收进最近错误发给 AI」原本各算各的，现在共用同一个兜底正则（`app.js BARE_ERR_RE`）。更重要的是：

**带 `[WARN]/[HINT]/[FAIL]` 标签的行，只按标签判，不再看文案关键词。**

踩到的是「MySQL 服务注册**可能失败**」这种措辞——它是一条 `[WARN]`，但关键词匹配把它判成了错误，于是每次启动都往「最近错误」里塞一条并不存在的故障，AI 拿到的标题还写着「错误日志」。

顺带修两处口径：

- `scope==='sys'` 的日志会被广播到 5 个分区，收集时现在**按正文去重并标 `[sys]`**，否则一条日志被当成五个组件各报一次错。
- 给 AI 的标题与实际内容一致。标题写「错误日志」而里面没有错误时，模型一定会硬编一个故障出来。

## 二、桌宠：启动成功不再亮红灯

`progState["*-start"].Running` 的语义是「**这一轮启动还在进行**」，不是「服务在不在跑」——启动收尾一律落 `false`。桌宠把它读成运行态，于是**每次启动成功都亮一次红灯**。

现在判结论只认 status 四态（ok / warn / fail / stopped），逻辑抽成纯函数 `ekSvcEvent`。顺带：`busy` 是共享状态，谁置的谁清，`ringOff` 不再无条件把别处的忙碌态顶成 idle（那个症状是「点了没反应」）。

## 三、设置 → 基础：从「一堆洞」到两列堆叠

原来的 `.set-grid` 是 auto 行对齐的 grid：同一行按最高的卡算行高，矮卡右侧留一大块空白。实测最丑的一行是「安装与分发」(100px) 挨着「手机访问」(340px)——右侧空 240px；末行单卡时右列整块空；整页 1661px。

改成显式两列（`.set-cols` 1fr 1fr）+ 每列内部 flex 纵向堆叠（`.set-col`），**同列内不再产生洞**。整页 1661 → 1524px，两列高度差 69px（门槛 120）。

空出来的位置用三个**真实存在、但一直没暴露**的配置项填上：

| 新卡片 | 字段 | 作用 |
|---|---|---|
| 备份目录 | `projects.backup_dir` | 留空用 exe 同级的 `backups`，输入框下实时提示实际位置 |
| 端口线索 | `projects.scan_ports` | 复验与端口诊断按这份清单找服务；留空自动推断 8080/8888 |
| 本机体检（只读） | `/api/health` | 权限 / 组件 / 前端服务 / 后端服务 / 待处理，五行 |

两个新字段都回传 `projectsBody()`——**同一字段只许一个写入口**，否则老「程序配置」页保存时会把它抹掉。

顺手修了链端显示：主机为空时原来会渲染出一个孤零零的 `:20200`，现在画成「—」。非管理员也不再着警告色——「不知道」不等于「有故障」。

## 四、英文界面：补 92 条，并且换了个能信的尺子

`tools/i18n_inventory.py --check` 报「缺失 320 条」，其中大量是把 JS 注释和代码片段当文案的噪声（MISS 列表里能直接看到 `if(ev.usage){`）。按那个数字补翻译是白干。

新增 `tools/i18n_gap.py`，只认三种用户真的会看到的中文：`t('…')` 字面量、模板里的文本节点、`placeholder`/`title`/`aria-label` 属性值。据此实测缺口 **92 条**，全部补齐后归零。

其中 4 条是配对卡里的句子被 `<b>` 从中间切断（`手机要和这台电脑在` / `<b>同一个 WiFi</b>` / `下；…`）——**被行内标签切碎的句子永远翻不成整句英文**，所以把那 4 行改成整句（去掉行内加粗）。

## 五、测试装置：成功即删隔离目录

每个 CDP 测试都会在 `tools/_<tag>/` 下放一份 15–28MB 的 exe 加一个 Chrome profile。跑完不删，累积起来 **17 个目录 255MB**（本次实测释放 249.6 MB，工作目录 463MB → 206MB）。

- 测试脚本现在**成功即删**（失败保留现场，那时 exe/配置/日志本身就是证据；`CDP_KEEP=1` 强制保留）。
- exe 不再要求手动 `go build` 进隔离目录：缺了就从仓库根那份复制一次。**删干净之后下一次跑不用再准备任何东西。**
- `tools/cdp_clean.py`：清理历史残留，默认只报告，`--yes` 才真删，`_shots`（留档截图）在白名单里。
