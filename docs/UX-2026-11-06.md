# EnvKit 用户体验优化建议（2026-11-06）

> 范围：只看用户体验，不谈测试 / 评测 / 架构重构。
> 方法：先 Grep 现有实现确认哪些已有，再搜 GitHub 对照可借鉴的交互模式。
> 本轮**没有改任何产品代码**。

## 一句话结论

EnvKit 的功能密度已经很高，摩擦主要不在"缺能力"，而在**「找不到、看不见、来不及反悔」**三件事：设置项散在 7 个面板里没有搜索，反馈只有一层 4.2 秒的 toast 且屏幕读不到，键盘用户几乎看不出焦点在哪。GitHub 上有一批成熟的原生 JS 方案可以直接抄交互契约——但**一个依赖都不该引**。

## 0. 先说边界：为什么是"抄模式"而不是"装库"

| 约束 | 依据 |
|---|---|
| 单文件 Go exe，前端 `go:embed`，`web/src/index.tpl.html` 里没有任何 CDN `<script>/<link>`（只有输入框 placeholder 和一个作者外链） | 前端现状 |
| 只有天气出网，新增外连默认关 + 白名单 | `MEMORY.md` 铁律 / `notifyUser()` 边界 |
| `web_build.py` 按文件顺序拼前端产物，`dist_check.py` 会扫敏感值 | 现有门禁 |

所以 `cmdk`、`Sonner`、Ant Design 这类 React 生态的东西**只能借理念**；真要引第三方代码，只有 `third_party/systray` 那种「本地 fork + LICENSE + 其余文件逐字节核对」的路子才安全。下面所有建议都能用现有原生 JS + CSS 落地，不新增依赖、不新增外连、不动权限闸。

## 3. 分级建议

### P0 · 日常摩擦最大 / 改动最值

**P0-1　命令面板 + 设置项搜索（Ctrl+K）**

- 现状：7 个 `panel`，设置页 3 个 tab / 13 张 `set-card`；找「GOPROXY 在哪」「静音开关在哪」只能人肉扫。全局没有统一快捷键注册，也没有快捷键帮助入口。
- 做法：建一个 `commands[]` 注册表（`id / title / section / keywords / handler / 是否需确认`），Ctrl+K 打开；模糊匹配按 Fuse 的思路做（typo 容忍 + 标题权重更高 + 中文关键词）；命中后跳到对应 panel、把目标卡滚到视窗并高亮 2 秒；再加一个「只看改过的设置」筛选，借 VS Code `@modified` 的语义（现有 `data-cfg` 字段能判脏）。
- 参考：ninja-keys（结构）、Fuse（打分）、VS Code（@modified / 重置默认）、cmdk（分组 + 无结果态）。
- **边界**：命令只负责「导航 + 打开面板 + 触发页面上已有的按钮」，**不新增任何执行能力**；所有写操作照旧走 428 确认卡，权限闸一字不动。

**P0-2　把 `toastUndo` 泛化成通用撤销**

- 现状：`20-shell.js:43` 的 `toastUndo` 已经是通用实现，注释却写着"目前只给「清空对话」的撤销用"，全项目唯一调用点是 `60-ai.js:124`。删除记忆、删除行动、删除备份、改配置这些可逆操作，现在要么弹确认框、要么直接就没了。
- 做法：定义可撤销动作登记表 `{label, snapshot, inverse, ttl}`，逐个接到已有的 `toastUndo`；借 Sonner 的 `action` 语义和「稳定 id 防堆叠」，借 toast 规范把带按钮的时长给到 5–7 秒、hover/focus 暂停计时、最多同时 3 条。
- **边界（重要）**：不可逆操作（覆盖库、`drop/truncate`、退出程序、清空全部数据）**继续走现有 428 + 红色 danger 确认框**，绝不因为"有撤销"就降级。撤销只是给可逆操作省一次打断，不是权限闸的替代品。
- 顺带收掉 `toast()` 的老问题：现在 4.2 秒固定、`while(box.children.length > 4) box.firstChild.remove()` 硬删、没有 `aria-live`、hover 不暂停（`20-shell.js:28`）。

**P0-3　键盘可达性底线（成本最低、最容易被漏）**

- 现状，三处都是代码实证：
  - `app.css:185` `input:focus,select:focus{outline:none;...}`、`app.css:1072` `.set-slider:focus{outline:none}` —— 删了 outline 只用背景色区分，没有统一的 `:focus-visible` 焦点环；
  - `index.tpl.html:1149` 的 `#confirm` 是普通 `.modal`，没有 `role="dialog"/aria-modal/aria-labelledby`；`askConfirm()` 打开不移动焦点，`closeConfirm()` 不归还焦点（`20-shell.js:375/401`），四条关闭路径（确定/取消/ESC/遮罩）里只有 ESC 是统一处理；
  - `index.tpl.html:1287` 的 `#toasts` 是空 div，没有 `aria-live`；全站只有 `#ai-msgs`（`index.tpl.html:1368`）有 `aria-live="polite"` —— 也就是说 **toast 提示对屏幕阅读器完全不存在**。
- 做法：① 全局 `:focus-visible` 给 2px 焦点环；② 6 个 `.modal` 补 dialog 语义，打开时按 APG 把初始焦点放在「取消」上（破坏性确认尤其重要），Tab/Shift+Tab 循环，任何关闭路径都把焦点还回触发按钮；③ `#toasts` 常驻并加 `role="status" aria-live="polite" aria-atomic="true"`，错误 toast 单独 `role="alert"`。
- 参考：W3C APG Dialog、`focus-trap`（借行为，不装包）。

### P1 · 该排进近期

**P1-4　首次引导 + 空态给"下一步"**

`.guide`（`index.tpl.html:101`）是 4 个静态步骤文字，不指向具体控件；空态全是纯文字「暂无…」。借 driver.js 做一次 3–4 步的高亮引导（选安装目录 → 配数据库 → 点检测 → 看日志分区），`localStorage` 记已看过、可重看；借 Ant Design Empty 把空态统一成「一句人话 + 一个动作按钮 + 一个为什么为空的说明」，例如"暂无经验"直接给「去跑一次检测」和累积规则说明。

**P1-5　日志只留窗口，别无限堆 DOM**

`20-shell.js:120` 是 `L.el.appendChild(div); L.n++; L.lines.push(line)` —— **没有上限、没有裁剪**。长时间跑安装/启动，单个 scope 能堆上万个节点，页面发涩、复制也没边界。借 TanStack/virtual 的窗口化思路：每个 scope 只保留最近 2000 行 DOM，更早的折进「显示更早的 N 行」；**内存里的 `lines[]` 仍全留**，导出/复制/AI 取「最近错误」都走内存，别把证据链剪掉；`BARE_ERR_RE`（`20-shell.js:65`）那个共用口径一字不动。

**P1-6　通知分级 + 分时静默**

`80-runtime.js:36` 只有一个 `#s_notify_mute` 全局静音，i18n 写着「已静音：气泡与 Webhook 都不会发」—— 要么全响要么全哑。借 Sonner 的语义分档：按「需要你动手 / 只是告知 / 后台完成」三档，只有第一档允许气泡和 Webhook；加「免打扰时段」和「同一问题 N 分钟内不重复」（`sys` 广播已有按正文去重的能力，能直接接上）。全局静音保留为总闸。

**P1-7　托盘降级给一个「重试」按钮**

11/6 修完 systray 之后，`TrayActions.Failed` 只发中文降级说明，用户看懂了但只能重启整个程序。设置页/托盘菜单加一个「重试托盘」，触发一次 fork 里已有的 `addIcon()`（就绪等待 + 有限重试都在），失败时把「任务栏在不在 / 重试几次」原样显示。不新增外连、不动权限闸，正好把上次诊断的遗留项收掉。

## 4. 只挑三件的话

**P0-1 命令面板 → P0-2 通用撤销 → P0-3 键盘可达性**。

前两条解决"找不到、来不及反悔"这两个每天都在发生的摩擦，第三条是纯前端、改动最小但收益最硬（现在 toast 对读屏用户等于不存在）。如果按成本从低到高排，先做 P0-3 也完全合理。P1-7 体量很小，做 P0 时顺手带上正好兑现 11/6 的托盘遗留项。
