## 一、引导页：从「一张图」改成「八屏可点的东西」

第一次打开 EnvKit 会自动播一段片头 + 8 屏介绍，每屏讲一件事：

| 屏 | 讲什么 | 能动手的地方 |
| --- | --- | --- |
| 01 | 开场：这台机器上有什么 | 剖面轮转，HUD 数字跟着走 |
| 02 | 五类信息汇聚到一处 | 悬停任一窗口，看它被谁接管 |
| 03 | 四步流程 | 点每一步，看输入 / 产出 / 会不会写盘 |
| 04 | 体检 | 自动扫一遍，出记分与「下一步」 |
| 05 | 日志 | 切五个分区，**插入一条演示异常** |
| 06 | AI 与桌宠 | 点三个问题看它会怎么答；桌宠动作与主界面一致 |
| 07 | 安全边界 | 切四档权限，看每档允许什么 |
| 08 | 收尾 | 8 章目录，可跳回任意一屏，「跟着做一遍」进真界面 |

几条刻意的取舍：

- **不做假进度**。v7 删掉了「重播汇聚」和「依次打勾」两个按钮——它们只让画面动一下，不代表任何真实进度。删掉按钮还不够，`done` 勾号状态与自动前进一起删了。
- **桌宠台词照抄主界面的**（`50-pet.js` 的台词表），不另编；另编就只是「看起来像」，接过来才是同一个角色。
- **每屏文案写「会写什么 / 只读还是写盘」**，与真实行为对齐。

右上角原来的「演示模式」标签换成了两个开关：**中英** 与 **明暗**。它们不是引导层自己的状态，而是直接调主界面同一套 `ekSetLang` / `applyTheme` —— 关掉引导，软件本身已经是切换后的样子（`localStorage` 同步落盘）。

英文模式下逐屏点开四步 / 四档 / 五分区 / 三轮问答 / 四种桌宠动作，界面残留中文 **0 条**。补的过程中修掉一个真 bug：03 屏路径里的 `\t` 被 JS 当制表符渲染，显示成 `C:EnvKit   ools`，中文界面下也是坏的。

### 观感

原来卡面 `#FFFCF8` 与页底 `#F7F4EF` 只差 8 个色阶、描边还是白色 0.8 —— 白卡画白边等于没有边。这版先压深画布（浅色 `#EFE8DD` / 暗色 `#090D14`）、把描边换成真的深发丝线，然后才是两件造型件（**每屏最多上两件**）：

- 内容板：实色卡面 + 底部 3px 厚度 + 左侧语义色条；
- 切角板：右上切 26px，沿切边压 2px 强调线。

切角卡必须用实色底——`clip-path` 会把 `box-shadow` 和 `backdrop-filter` 一起裁掉，所以厚度改用 `inset` 阴影表达。

背景加了一层极慢的粒子（几十个漂移点，近则连线，指针推开）。**没有引第三方库**：这层只画点和线，tsParticles 之类约 90KB、还要从 `/vendor/` 同域加载，换不来效果只换来一个依赖。`prefers-reduced-motion` 下只画一帧静态分布。

## 二、AI 能读文档了

之前把 docx / xlsx / pptx / pdf 拖进对话区，只能靠用户自己贴正文。现在：

- 拖进来的文档变成**文件附件**，由后端抽取正文，不再往输入框里灌文本；
- 「+ 号」选中的文档走同一条抽取链路，文件卡片按格式配色；
- **大文件真分页**：`read_file` 之前只能看前 64KB，现在按页读，文档附件全程可读；
- 解析修了三处真实缺陷：PDF 碎片拼接、xlsx 列名与表名、pptx 页序；
- 文档正文不再污染意图判定——带文档提问时先弹写操作确认卡；材料模式与执行模式隔离。

配套修了一个更隐蔽的问题：文档附件发不到模型，原因是请求体白名单漏了 `docs` 字段。

### 图纸语汇的三条硬规则

- 非等比缩放下**圆优于多边形**：十二边形轮对会被压成六角螺母，`<circle>` 变成椭圆仍像轮子。
- **线宽必须分级**：第一版所有小设备箱都用 2.2px，远看像贴了一排便签，主轮廓反而被淹没。
- `<rect>` 默认黑填充，铺满画布的 pattern 块必须显式 `fill="url(#…)"`，否则整屏刷黑。
