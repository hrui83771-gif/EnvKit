## 一、手机端：地址带 `?debug` 出现调试台（vConsole）

手机页面是自包含单文件，出了问题只能靠猜——控制台在电脑上，报错在手机上。

现在给手机地址加 `?debug`，右下角会出现 vConsole 面板：可看 `console.log`、网络请求、DOM、存储。**平时不加载**——只有地址里带 `?debug` 时，页面才会去请求同域的 `/vendor/vconsole.min.js`（`go:embed` 内嵌，不走任何外网 CDN），普通用户零流量、零干扰。

用法：

```
http://<电脑IP>:18766/?debug            # 带配对码时 ?debug 追加在后面
http://<电脑IP>:18766/?code=123456&debug
```

CSP 未放宽：脚本来自同域，`script-src 'self'` 本来就允许。

## 二、本机体检：从「有问题」到「该怎么办」

`/api/health` 里的 `issues[]` 一直带 `action` 字段（该做什么），但界面上从来没显示过，只显示「N 个警告」。现在**逐条显示「问题 + 建议」**，看到警告的同时就知道下一步点哪里。

同时补两项一直缺的入口：

- **一键打开目录**：备份目录、日志目录不再是「复制这段路径自己去资源管理器粘贴」，新增 `POST /api/open/path`——**白名单校验 + 需确认 + 写审计**，不接受任意路径。
- **备份保留份数进配置**：`prunedBackupsKeep = 10` 从写死的常量搬进 `dev.backup_keep`（1–100，默认 10）。这是 v3.4 那条「写死常量改运行时配置」的欠账。

## 四、试过并撤回：mDNS 主机名（`<本机名>.local`）

原本想做「IP 变了旧二维码照样能开」——广播 `_envkit._tcp.local`，二维码里写 `<本机名>.local`，手机靠 mDNS 解析。

**实测不可用**：不少路由器和手机不转发组播 DNS，`<本机名>.local` 解析不到，页面直接打不开。已完整回退（删 `lanmdns.go`、二维码回到「首个可达 IP」、Host 白名单撤回 `.local` 放行、`go.mod` 去掉 `zeroconf` 及其 4 个间接依赖）。

结论写在这里，是为了下次不再重走：**mDNS 在"用户自己的局域网"里不是可靠假设**，除非同时提供 IP 回退，否则不能作为默认寻址方式。
