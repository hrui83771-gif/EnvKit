# EnvKit v3.2.0

**界面重组、托盘化，以及 AI 记忆层的第一版。**

发布日期：2026-10-25
产物：`EnvKit.exe`（11.35 MB，单文件）
SHA256：`a18a5ea98535144e004e158645726ae6c052847bfa79df1b92c5503fe0555978`

升级自 3.1 的重构版，主要动的是"东西放在哪"和"AI 记住的东西算不算数"，核心执行路径没有重写。

---

## 一、界面

**个人中心**
顶栏右侧原来是一排同权重按钮（杀软白名单 / EN / 暗色 / 提权）。现在收成一个头像 + 昵称的下拉：语言、主题、杀软、深度清除、提权、退出都放进去。支持 6 个预设头像和自定义上传（画布裁成 128×128，只存本机 localStorage），昵称会用在桌宠的开场问候里。

**侧边栏**
去掉了六个状态灯——同一份状态在顶部胶囊、步骤条、运行状态卡里已经出现三次，第四份最小也最吵。导航改成"浅底 + 左侧细条"标记当前位置；运行状态改成文字胶囊（正常 / 未启动 / 不通），WeBASE 的长链接收成一行「打开 ↗」；「退出程序」移进个人中心。

**链端**
配置项（SSH、目录、守护）收进一个默认收起的折叠块；操作面只留 **检测 / 启动 / 终端** 三键，启动做成下拉（节点 / WeBASE）；端口与链信息独立成只读结果卡。

**其它**
- 审计页两张趋势图收进「审计趋势」折叠块
- 配置页拆成 4 个 tab（目录与库 / 启动方式 / 数据库 / 依赖），业务 id 一个没改
- AI 回复支持 Markdown、表格、代码高亮（marked + highlight.js 内嵌，不走 CDN）
- 支持 `#config` 深链，托盘菜单直接落到配置页
- 修正日志折叠按钮：收起时按钮应显示「展开」

## 二、AI

**记忆与经验 v1**
- 「已失效」的记忆现在会随接口返回并在界面上标出来；旧实现只在内存里算，界面永远看不到
- 记忆面板新增「试算」：输入一句话任务，显示本轮会注入哪些记忆/经验、每条为什么没注入
- 记忆条数到上限时保存会报错，不再静默切掉刚写入的那条；always 记忆超过每轮上限时保留最新的并写明原因
- 经验：先滤掉失效/被否决的再选名额；任务不匹配时不再硬塞前 N 条

**缓存**
- 滚动摘要的触发从"24 条消息"改成"约 5000 token"，切分点仍按 6 条量化，避免摘要缓存被打碎
- 工具结果截断按信息密度分档（诊断 3000 / 日志 2000 / 查询与审计 1600 / 搜索 1200 / 目录 1000 字节）
- 每一步上游请求的日志增加「新增占比」（miss/prompt），超过 50% 会告警——摘要重建、确认重建、超大结果会在这里现形

**链端复验**
端口与进程数两次 SSH 往返改为并发（errgroup），可达性门禁仍然先跑；判据未改。

## 三、托盘

新增系统托盘（systray）：

- 右键：打开控制台 / 程序配置 / 打开日志目录 / 隐藏窗口到托盘 / 退出
- 「退出」会先停掉前端和后端，不留孤儿进程
- 隐藏状态写入 `config.json` 的 `tray_hidden`，下次启动沿用；只有托盘就绪后才会隐藏窗口
- 托盘图标默认可能在 Windows 的 `^` 溢出区里，拖到任务栏即可常驻

## 四、修复

- 请求体丢失（根因：先写 SSE 响应头、后读 body）——此前每条对话都可能只剩 6 条兜底消息
- 日志折叠按钮初始文案与状态不一致，导致"点两次才正常"
- 英文切回中文时，夹着 `<code>` 的句子不还原
- 记忆上限与 always 记忆截断的静默丢弃
- 链端 SSH 复验串行导致的多余等待

## 五、升级说明

- 构建需要 Go 1.26+（`go.mod` 已写明；x/sys 等依赖要求 1.26）
- `config.json` 新增可选字段 `tray_hidden`，旧配置可直接用
- 昵称/头像存在浏览器 `localStorage` 的 `ek-profile`，不写配置、不进分发包
- 新增 Go 依赖：`github.com/getlantern/systray`、`golang.org/x/sync`；前端新增内嵌 `marked` / `highlight.js`，许可已补进 `THIRD-PARTY-NOTICE.md` 与 `LICENSES/`
